# Локальная проверка

1. Запустите «Докер Десктоп», затем `ЗАПУСТИТЬ-СЕРВЕР.cmd`. В открывшейся панели создайте администратора и разрешите открытую регистрацию либо создайте приглашение.
2. Если клиент показывает старый профиль, закройте его и запустите `СБРОСИТЬ-КЛИЕНТ.cmd`. Введите `ДА`.
3. Запустите `ЗАПУСТИТЬ-КЛИЕНТ.cmd`. Нажмите `Create local profile`, задайте имя и пароль, сохраните код восстановления.
4. Нажмите `+` слева, введите `https://openspace.lan`, затем нажмите `Find server` и `Connect`. Если сервер требует приглашение, вставьте его код.
5. Создайте второго пользователя в другом проверочном профиле или на другом устройстве. Проверьте сообщения, файл и голосовой разговор между двумя пользователями.
6. Проверьте микрофон, камеру, показ экрана и восстановление после отключения сети на 15 секунд.
7. Убедитесь, что обычный пользователь не видит административные действия.

Для настольного приложения используйте `УСТАНОВИТЬ-КЛИЕНТ-WINDOWS.cmd`. Для остановки сервера — `ОСТАНОВИТЬ-СЕРВЕР.cmd`; данные сервера при этом сохраняются.
