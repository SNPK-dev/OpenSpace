# Spec: server-settings-ui-followup

## Capability

Server action settings use semantic icons, avatar image inputs, and categorized navigation.

### Requirement: avatar-image-field

Profile and server settings provide file selection, preview, replace, and clear actions.

### Requirement: categorized-server-settings

Server settings show categories on the left and selected content on the right.

### Requirement: semantic-dropdown-icons

Dropdown state uses semantic chevron icons.
