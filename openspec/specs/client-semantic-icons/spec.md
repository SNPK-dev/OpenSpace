# Client semantic icons

## Purpose

Provide consistent, accessible iconography across web-client and desktop-win.

## Requirements

### Requirement: semantic-client-icons

Web-client and desktop-win MUST use consistent semantic icons for voice, text, DM, expand/collapse, and logout/lock actions instead of textual pseudo-icons.

### Requirement: accessible-icon-controls

Icon-only interactive controls MUST retain an accessible name.
